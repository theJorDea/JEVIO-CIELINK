# Журнал сессий CIELINK

Локальное рабочее место оператора: список звонков, дорожки по ролям, реплики с таймкодами, выводы анализа, условия предложения и квитанция CRM. Данные загружаются только из FastAPI; демонстрационных записей во фронтенде нет.

## Запуск

1. Из корня репозитория запустите FastAPI: `uv run --frozen uvicorn cielink.api:app --host 127.0.0.1 --port 8000`. Нужны маршруты `GET /api/sessions` и `GET /api/sessions/{id}`.
2. В отдельном терминале (Node.js 22.12+):

   ```sh
   cd dashboard
   npm ci
   npm run dev
   ```

3. Откройте локальный адрес из вывода Vite (обычно `http://127.0.0.1:5173`). Запросы `/api` и записи под этим префиксом передаются на `http://127.0.0.1:8000`.

`npm run build` проверяет типы и собирает сайт в `dist/`. При отдельной раздаче этих файлов проксирование `/api` нужно настроить на сервере: dev-прокси не входит в сборку.

В открытой вкладке список и выбранная карточка обновляются через пять секунд после завершения предыдущего запроса. При сбое интервал растёт до минуты; последнее успешное значение остаётся на экране с предупреждением. Скрытая вкладка не начинает новые запросы.

Для сверки выберите дорожку и нажмите реплику. Позиция в записи равна `(offset_ms − start_ms) / 1000` секунд. Без доступного аудио или подходящего таймкода реплика остаётся читаемой, а переход отключается с пояснением.
