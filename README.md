# CIELINK · Подключение домашнего интернета за один звонок

Проект команды JEVIO-CIELINK для [SkyNet Signal, кейс №2](https://aiskyhack.itmobc.ru/team-6941db672243d5f01d53/). **Статус: локальная учебная сборка.** Доступные команды — ниже; roadmap описывает целевой продукт. Подтверждённых замеров на мобильной сети и публичного тестового номера пока нет. Внутренние API SkyNet не предполагаются доступными.

**Для клиента:** позвонить с обычного телефона, узнать условия именно для своего дома, поправить адрес или бюджет, получить номер согласованной заявки либо подтверждение проверки дома. **Для SkyNet:** понять по записи, что услышал клиент, какие условия применились и что попало в CRM. Перед выпуском новой акции — проверить на тех же ситуациях, какие обещания изменятся.

> «Дом восемнадцать, корпус один… Нет, второй. И до девятисот — это после скидки тоже». Агент прекращает речь, сохраняет бюджет, отбрасывает проверку первого корпуса. Если данных о втором нет, предлагает проверить **второй корпус**, а не подключить первый. «Да, я слышу» не считается заказом.

## Функциональность по этапам

| Этап | Возможности |
|---|---|
| Основа | Настоящий входящий номер → SIP → русская речь; проверка дома; 1–2 доступных тарифа с ценой сейчас и после акции; согласие и номер заявки. Отказ, неизвестный адрес и сбой — разные исходы. |
| Отличие проекта | Speculative orchestrator запускает проверки, пока человек говорит. Перебивание останавливает озвучку; поправка отменяет только зависимые результаты. Три режима сравнения на одних входах. |
| Рабочее место компании | Запись по ролям, транскрипция, таймкоды обещаний, сопоставление с версией каталога и CRM. Из эпизода — тест; из черновика акции — отчёт об изменениях до публикации. |
| После демо | Тёплый перевод, выбор корпуса по одноразовой ссылке, подтверждённое окно монтажа при наличии расписания, аналитика неизвестного покрытия. Гипотезы и условия запуска — в roadmap. |

## Данные и запуск

Цены и ограничения — с [сайта SkyNet](https://skynet.ru/internet/tarify/), с URL и датой просмотра; доступность для конкретного дома, клиенты, очереди и заявки в демо — **учебные**. Реальных клиентов, телефонные номера абонентов, аудио без разрешения и ключи провайдеров в Git не добавляем.

### Запуск локального API

Нужны `uv` и Python 3.11–3.14 (проверяем на 3.13). Из корня клона:

```sh
uv sync --frozen --python 3.13
uv run --frozen pytest -q
uv run --frozen uvicorn cielink.api:app --host 127.0.0.1 --port 8000
```

`http://127.0.0.1:8000/health` возвращает `{"status":"ok","mode":"training"}`; `/docs` открывает интерактивную схему. Ключи и PostgreSQL для запуска доменных тестов не требуются. `.env.example` содержит только несекретные настройки; если копируете их в `.env`, добавьте `--env-file .env` к команде uvicorn. Не выставляйте учебный API в публичную сеть.

### Телефонный стенд (опционально)

Для входящего тестового вызова с собственной АТС есть [инструкция для Asterisk](telephony/README.md): локальные Vosk и синтез речи, та же логика согласия и CRM, резервный маршрут к оператору. В режиме EAGI голосовая активность может прервать озвучивание. Агент просит повторить фразу после сигнала; наложившиеся слова не распознаются и не считаются согласием. Обычный AGI остаётся пошаговым вариантом без перебивания. В комплект не входят рабочий номер и SIP-транк. Перед пилотом: [контракты и проверка отката](docs/pilot-contracts.md).

### Панель для разбора звонков

При работающем FastAPI откройте второй терминал: `cd dashboard`, `npm ci`, `npm run dev`. Используйте локальный URL из консоли Vite. В третьем терминале из корня запустите `uv run python -m cielink.review --watch --interval 2`. Начните учебный разговор на `/voice`: сессия автоматически появится в списке, после завершения карточка покажет квитанцию и результат фоновой сверки. Воркер сверяет числа и операции **правилами**, не вызывает внешнюю LLM. В браузерном стенде звук по умолчанию не записывается: без импортированных аудиодорожек плеер не изображает запись. [Подробнее о панели](dashboard/README.md). Чтобы прослушать разрешённую учебную запись, [привяжите две WAV-дорожки к сессии](docs/recordings.md), указав отдельное смещение каждой от начала разговора.

### Разговор без повторного адреса

Попробуйте после «Учебная 18, корпус 1»: «До двух тысяч в месяц», «А сколько будет стоить после акции?», затем «Нет, второй». Агент уточняет именно корпус; ответ «да» на уточнение адреса не оформляет заказ. Если у клиента нет своего роутера, условия для собственного оборудования нельзя молча использовать для заявки. Правила разбора работают локально: обязательного LLM-провайдера нет, цена берётся из предложения, запись — только через CRM. [Воспроизводимый показ одного разговора с сохранением его карточки](docs/replay.md#один-разговор-и-его-карточка-для-защиты).

### Опережающие чтения

`CIELINK_READ_MODE=sequential` обрабатывает только финальную реплику; `early` заранее готовит разбор адреса без запросов покрытия; `speculative` (по умолчанию) после двух совпадающих гипотез дома начинает фоновые чтения покрытия и каталога. Новая сумма требует пересчёта предложения, но не покрытия. В событии `reply_generated.reads` видны старт, готовность, отмена и использование. Фикстуры работают локально: это не измерение задержки мобильной сети.

### Браузерный стенд (без номера)

[Программный повтор в трёх режимах](docs/replay.md): `uv run --locked python -m cielink.replay --output local-data/replay.json` (каталог `local-data` должен существовать). [Отдельная проверка через микрофон и шаблон акустических замеров](docs/browser-trials.md).

Откройте `http://127.0.0.1:8000/voice` в браузере. Подключитесь, разрешите микрофон, скажите «Учебная улица, дом 18, корпус первый» и прервите ответ словами «стоп, корпус второй». Попробуйте трижды, лучше в наушниках. Для расчёта используются учебное покрытие и [исторический каталог](docs/catalog-data.md), а не действующие системы SkyNet. Например: «Учебная улица, дом 18 корпус первый, до 2000 в месяц», затем «стоп, корпус второй». Поддержка русского распознавания и голосов зависит от ОС и браузера; браузерный сервис может передавать звук своему поставщику. Если голос недоступен, ручной ввод проверяет тот же WebSocket, но не заменяет акустический тест. `CIELINK_STT=text` / `CIELINK_TTS=text` отключают браузерные сервисы; `CIELINK_LLM=rules` — локальные правила без платной модели. После окончания озвучки подтвердите конкретное действие: «да, подключайте» или «да, проверьте адрес». До согласия заказ или проверка не создаётся; учебная панель сохраняет транскрипт с начала сессии, используйте только вымышленные данные; «да, я слышу» не создаёт заявку. В текстовом режиме факт отображения условий учитывается отдельно от окончания озвучки. [Учебная CRM, SQLite и PostgreSQL](docs/crm.md).
